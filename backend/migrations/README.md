# Deployment migrations

The local SQLite prototype does not use migration history: `app/db/migrate.py`
adds new columns at startup so an existing `voicekyc.db` keeps working.

For deployment (PostgreSQL in `docker-compose.yml`), create and review Alembic
revisions from `backend/`:

```powershell
alembic revision --autogenerate -m "initial schema"
alembic upgrade head
```

`migrations/env.py` reads `DATABASE_URL` from the application settings, so run
Alembic with the same environment as the backend. Review autogenerated
revisions before committing them; startup migration is not a substitute for a
versioned deployment migration.
